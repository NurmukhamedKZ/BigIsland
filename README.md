# BigIsland

Остров у выреза камеры MacBook. В обычной работе его не видно, при наведении курсора на вырез он плавно вырастает. Внутри — вкладки‑фичи.

Нативное приложение на Swift + SwiftUI: почти не нагружает процессор в простое, анимации идут на частоте экрана.

## Фичи

### Скриншоты
- Ловит новые скриншоты из системной папки скриншотов (⇧⌘3, ⇧⌘4, ⇧⌘5).
- Ловит **любые** картинки из буфера обмена (⌃⇧⌘4, копирование картинки из браузера и т. п.) и сохраняет их во временный PNG.
- Скриншот можно перетащить из острова в любое приложение (drag & drop).
- Двойной клик — открыть. Правый клик — «Открыть», «Показать в Finder», «Убрать с острова».
- Хранится до 40 последних. После выхода из приложения список пустой.

### Помодоро
- Секундомер фаз: **учёба 50 мин → отдых 10 мин**, 4 круга, после четвёртого — **отдых 30 мин**.
- Фазы сами не переключаются. Учёба идёт, пока не нажмёшь «Отдых»; отдых — пока не нажмёшь «Учиться». Так можно учиться дольше 50 минут.
- Звук на цели: «Glass» на 50 мин учёбы, «Hero» на 10/30 мин отдыха. Счёт продолжается дальше.
- ↺ — сбросить цикл (набранное время учёбы остаётся).
- «Сегодня» — время учёбы за день; календарь месяца — время по каждому дню и сумма за месяц. Дни без учёбы показывают тусклый номер дня.
- История хранится навсегда: `~/Library/Application Support/BigIsland/pomodoro.json` (атомарная запись, раз в минуту во время учёбы). Если файл не прочитался, он не перезаписывается — рядом кладётся копия `pomodoro.broken-*.json`.
- Учёба через полночь делится между двумя днями.

### Озвучка
- Вставь текст (⌘V) в поле, и он сразу начнёт звучать. Набранный вручную текст озвучивается кнопкой «Озвучить».
- Модель Grok Voice TTS 1.0 через OpenRouter (~$15 за 1 млн символов). Нужен интернет.
- Пауза, «Дальше», ⏹ — остановить. Озвучка продолжается и при свёрнутом острове.
- Длинный текст режется по предложениям; заранее качается не больше 2 фрагментов вперёд, так что после остановки деньги не тратятся.
- Ключ OpenRouter хранится в связке ключей:
  ```sh
  security add-generic-password -U -s BigIsland -a openrouter -w
  ```
  (команда спросит ключ). При первой озвучке macOS спросит доступ к связке ключей — «Всегда разрешать».

## Требования

- macOS 14+, лучше MacBook с вырезом (на внешних мониторах остров тоже работает — невидимая зона по центру строки меню).
- Swift 6 (хватает Command Line Tools, Xcode не обязателен).

## Сборка и запуск

```sh
./build.sh && open build/BigIsland.app
```

После изменений в коде:

```sh
pkill -x BigIsland; ./build.sh && open build/BigIsland.app
```

Выйти — кнопка ⏻ в острове.

Проверка логики (XCTest без Xcode недоступен):

```sh
swift run BigIsland --selftest
```

## Советы и известные особенности

- **Скриншот появляется только через ~5 секунд.** Пока в углу висит плавающая миниатюра, macOS не записывает файл. Отключить: ⇧⌘5 → «Параметры» → снять «Показывать плавающую миниатюру».
- **Запрос доступа к «Документам».** Нужен, чтобы видеть папку скриншотов. Подпись привязана к bundle id, поэтому после пересборки спрашивать не должно.
- **Сменил папку скриншотов** — перезапусти приложение (папка читается при старте).
- В остров попадает любая скопированная картинка, а не только скриншоты — так задумано.
- **Помодоро и сон Mac.** Если закрыть крышку во время учёбы, время сна посчитается как учёба. Если приложение было выключено больше 2 минут посреди учёбы, этот промежуток не считается.
- Нет автозапуска при входе в систему и нет настроек (пока).

## Структура

```
Sources/BigIsland/
├─ main.swift                     точка входа, приложение без иконки в Dock
├─ AppDelegate.swift              реестр фич, по острову на каждый экран, монитор мыши
├─ Island/
│  ├─ IslandController.swift      окно (NSPanel), геометрия выреза, наведение
│  └─ IslandView.swift            форма острова, анимации, вкладки
└─ Features/
   ├─ IslandFeature.swift         протокол фичи
   ├─ Screenshots/ScreenshotsFeature.swift
   └─ Pomodoro/
      ├─ PomodoroFeature.swift    фазы, звуки, хранение по дням, --selftest
      └─ PomodoroView.swift       секундомер и календарь месяца
build.sh                          сборка .app (Info.plist, ad-hoc подпись)
```

## Как добавить фичу

1. Создай `Sources/BigIsland/Features/<Имя>/<Имя>Feature.swift`:

```swift
import SwiftUI

@MainActor
final class ClockFeature: ObservableObject, IslandFeature {
    let id = "clock"
    let title = "Часы"
    let icon = "clock"          // SF Symbol
    let contentHeight: CGFloat = 150  // необязательно, по умолчанию 150

    func start() {}             // подписки, таймеры, наблюдатели
    func stop() {}
    func makeView() -> AnyView { AnyView(Text(Date(), style: .time)) }
}
```

2. Добавь одну строку в `features` в `AppDelegate.swift`:

```swift
let features: [any IslandFeature] = [
    ScreenshotsFeature(),
    ClockFeature(),
]
```

Фича сама станет вкладкой; при переключении вкладок остров плавно меняет высоту. Чтобы убрать — удали строку (и папку).

## Настройка анимаций

`Sources/BigIsland/Island/IslandView.swift`:

| Что | Где |
|---|---|
| Рост/сжатие формы | `.animation(.spring(response: 0.38, dampingFraction: 0.8), …)` |
| Появление/исчезновение контента | `.transition(.scale(scale: 0.3, anchor: .top)…animation(.easeIn(duration: 0.15)))` |
| Скругление | `radius` (26 открыт / 8 закрыт) |

Ширина открытого острова — `expandedWidth` в `IslandController.swift`, высота — `contentHeight` у каждой фичи.
