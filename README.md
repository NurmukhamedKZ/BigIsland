# BigIsland

Остров у выреза камеры MacBook. В обычной работе его не видно, при наведении курсора на вырез он плавно вырастает. Внутри — фичи: кнопка слева от камеры показывает текущую, по нажатию открывается список всех.

Нативное приложение на Swift + SwiftUI: почти не нагружает процессор в простое, анимации идут на частоте экрана.

## Фичи

### Скриншоты
- Ловит новые скриншоты из системной папки скриншотов (⇧⌘3, ⇧⌘4, ⇧⌘5).
- Ловит **любые** картинки из буфера обмена (⌃⇧⌘4, копирование картинки из браузера и т. п.) и сохраняет их во временный PNG.
- Скриншот можно перетащить из острова в любое приложение (drag & drop).
- Двойной клик — открыть. Правый клик — «Открыть», «Показать в Finder», «Убрать с острова».
- Хранится до 40 последних. После выхода из приложения список пустой.

### Помодоро
- Секундомер фаз: **учёба 50 мин → отдых 10 мин**, 4 круга, после четвёртого — **отдых 30 мин**.
- Фазы сами не переключаются. Учёба идёт, пока не нажмёшь «Отдых»; отдых — пока не нажмёшь «Учиться». Так можно учиться дольше 50 минут.
- Звук на цели: «Glass» на 50 мин учёбы, «Hero» на 10/30 мин отдыха. Счёт продолжается дальше.
- ↺ — сбросить цикл (набранное время учёбы остаётся).
- «Сегодня» — время учёбы за день; календарь месяца — время по каждому дню и сумма за месяц. Дни без учёбы показывают тусклый номер дня.
- История хранится навсегда: `~/Library/Application Support/BigIsland/pomodoro.json` (атомарная запись, раз в минуту во время учёбы). Если файл не прочитался, он не перезаписывается — рядом кладётся копия `pomodoro.broken-*.json`.
- Учёба через полночь делится между двумя днями.
- Двойной клик по дню календаря — поправить время учёбы вручную (часы и минуты; Enter/✓ — сохранить, Esc/✕ — отмена, 0 — убрать день).

### Озвучка
- Вставь текст (⌘V) в поле, и он сразу начнёт звучать. Набранный вручную текст озвучивается кнопкой «Озвучить».
- Модель Grok Voice TTS 1.0 через OpenRouter (~$15 за 1 млн символов). Нужен интернет.
- После запуска кнопка становится «Повтор»: озвучка играется заново из памяти, без новых запросов к API. Изменил текст — снова «Озвучить», старая озвучка забывается. После выхода из приложения не сохраняется.
- ⏸ / ▶ — пауза, ⏹ — остановить. Озвучка продолжается и при свёрнутом острове.
- Длинный текст режется по предложениям; заранее качается не больше 2 фрагментов вперёд, так что после остановки деньги не тратятся.
- Ключ OpenRouter лежит в `~/Library/Application Support/BigIsland/.env` (вне репозитория, права 600):
  ```sh
  mkdir -p ~/Library/Application\ Support/BigIsland
  (umask 077; echo 'OPENROUTER_API_KEY=sk-or-…' > ~/Library/Application\ Support/BigIsland/.env)
  ```
  Не связка ключей: у приложения ad-hoc подпись, и macOS спрашивала бы пароль после каждой пересборки.

### Набор
- Запускает `~/.local/bin/typeclip 5`: через 5 секунд печатает буфер обмена как нажатия клавиш. За это время ставишь курсор в нужное поле — пригодится там, где вставка запрещена.

### Раскладка
- Автопереключение RU ⇄ EN, как Punto Switcher: набрал `ghbdtn` — после пробела станет «привет», и раскладка переключится. Работает и наоборот: `сщтые` → `const`.
- Своя реализация по идеям открытых аналогов ([layout-switcher](https://github.com/mikakostoev/layout-switcher), [RuSwitcher](https://github.com/rashn/RuSwitcher), [KeySwitcher](https://github.com/graninilya/keyswitcher)). Сети нет, набранный текст никуда не пишется — в памяти только текущее слово и пара коротких перед ним.
- Решает системный словарь macOS: меняем, только если как набрано — не слово, а в другой раскладке — слово. Словарь не знает ни того, ни другого (жаргон, формы: `ltdjgcjd` → «девопсов») — решает статистика буквосочетаний (таблица из частотных списков [FrequencyWords](https://github.com/hermitdave/FrequencyWords), CC-BY-SA).
- Знает частые команды терминала, которых нет в словаре: `св ..` → `cd ..`, так же `ls`, `rm`, `mv`, `cp`, `ps`, `pwd`, `mkdir`, `chmod`, `pip`, `git`, `npm` и др. Список — `shortWords` / `knownWords` в `LayoutRules.swift`.
- Короткие слова чинятся задним числом, когда следующее слово переключилось: `z b ghbdtn` → «я и привет».
- **Режим кода** в редакторах и терминалах (VS Code, Cursor, Zed, Xcode, JetBrains, cmux, Terminal, iTerm2, Ghostty и др.): латиница, похожая на код (`a.b`, `x[i]`, `getUser`, слова короче 3 букв), никогда не превращается в русский; Return и Tab не запускают замену (автодополнение). Русский текст в комментариях и промптах по-прежнему чинится.
- **Двойной ⌥** — перевести последнее слово вручную. Если это была наша автозамена — откатит её и запомнит слово в исключения (сбросить — кнопкой во вкладке).
- Только русская и английская раскладки, остальные (например, казахская) не трогает. В полях паролей не работает.
- Нужен доступ: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → BigIsland. Приложение само попросит при первом запуске.
- Памяти — около 1,5 МБ (таблица буквосочетаний), процессор в простое не нагружает.

### Не спать
- Аналог Amphetamine: Mac не засыпает даже с закрытой крышкой, можно убрать в сумку. Экран гаснет, остальное работает.
- Делает `pmset -a disablesleep 1`. Первое включение спрашивает пароль и ставит `/etc/sudoers.d/bigisland` — без пароля разрешены только `pmset -a disablesleep 0` и `1`. Убрать: `sudo rm /etc/sudoers.d/bigisland`.
- Выключается при выходе из BigIsland и на батарее ниже 10% (проверка раз в минуту, только пока включено).
- Состояние читается из `pmset -g`, так что после падения приложения вкладка показывает правду. Выключить вручную: `sudo pmset -a disablesleep 0`.

## Требования

- macOS 14+, лучше MacBook с вырезом (на внешних мониторах остров тоже работает — невидимая зона по центру строки меню).
- Swift 6 (хватает Command Line Tools, Xcode не обязателен).

## Сборка и запуск

```sh
./build.sh && open build/BigIsland.app
```

После изменений в коде:

```sh
pkill -x BigIsland; ./build.sh && open build/BigIsland.app
```

Выйти — кнопка ⏻ в острове.

Установить в «Программы» с автозапуском при входе в систему (после изменений в коде — та же команда):

```sh
./build.sh --install
```

Автозапуск включается один раз при первом запуске из /Applications. Выключить: Системные настройки → Основные → Объекты входа.

Проверка логики (XCTest без Xcode недоступен):

```sh
swift run BigIsland --selftest
```

## Советы и известные особенности

- **Скриншот появляется только через ~5 секунд.** Пока в углу висит плавающая миниатюра, macOS не записывает файл. Отключить: ⇧⌘5 → «Параметры» → снять «Показывать плавающую миниатюру».
- **Запрос доступа к «Документам».** Нужен, чтобы видеть папку скриншотов. Подпись привязана к bundle id, поэтому после пересборки спрашивать не должно.
- **Сменил папку скриншотов** — перезапусти приложение (папка читается при старте).
- В остров попадает любая скопированная картинка, а не только скриншоты — так задумано.
- **Раскладка ничего не делает** — проверь «Универсальный доступ» (вкладка покажет «Нужен «Универсальный доступ»»). Если остался доступ от старой сборки, выключи и включи BigIsland в списке.
- **Помодоро и сон Mac.** Если закрыть крышку во время учёбы, время сна посчитается как учёба. Если приложение было выключено больше 2 минут посреди учёбы, этот промежуток не считается.
- Нет настроек (пока).

## Структура

```
Sources/BigIsland/
├─ main.swift                     точка входа, приложение без иконки в Dock
├─ AppDelegate.swift              реестр фич, по острову на каждый экран, монитор мыши
├─ Island/
│  ├─ IslandController.swift      окно (NSPanel), геометрия выреза, наведение
│  ├─ IslandView.swift            форма острова, анимации, меню фич
│  └─ Theme.swift                 цвета, кнопки, стиль нажатия
└─ Features/
   ├─ IslandFeature.swift         протокол фичи
   ├─ Screenshots/ScreenshotsFeature.swift
   ├─ Pomodoro/
   │  ├─ PomodoroFeature.swift    фазы, звуки, хранение по дням, --selftest
   │  └─ PomodoroView.swift       секундомер и календарь месяца
   ├─ Speech/SpeechFeature.swift  озвучка через OpenRouter
   ├─ TypeClip/TypeClipFeature.swift
   ├─ Layout/
   │  ├─ LayoutFeature.swift      перехват клавиш, замена слова, вкладка
   │  ├─ LayoutRules.swift        решение «не та раскладка», буфер слов, проверки
   │  └─ LayoutTrigrams.swift     таблица буквосочетаний (сгенерирована)
   └─ Awake/AwakeFeature.swift    не спать с закрытой крышкой (pmset disablesleep)
build.sh                          сборка .app (Info.plist, ad-hoc подпись)
```

## Как добавить фичу

1. Создай `Sources/BigIsland/Features/<Имя>/<Имя>Feature.swift`:

```swift
import SwiftUI

@MainActor
final class ClockFeature: ObservableObject, IslandFeature {
    let id = "clock"
    let title = "Часы"
    let icon = "clock"          // SF Symbol
    let contentHeight: CGFloat = 150  // необязательно, по умолчанию 150

    func start() {}             // подписки, таймеры, наблюдатели
    func stop() {}
    func makeView() -> AnyView { AnyView(Text(Date(), style: .time)) }
}
```

2. Добавь одну строку в `features` в `AppDelegate.swift`:

```swift
let features: [any IslandFeature] = [
    ScreenshotsFeature(),
    ClockFeature(),
]
```

Фича сама появится в списке фич; при переключении остров плавно меняет высоту. Чтобы убрать — удали строку (и папку).

## Настройка анимаций

`Sources/BigIsland/Island/IslandView.swift`:

| Что | Где |
|---|---|
| Рост/сжатие формы | `.animation(.spring(response: 0.38, dampingFraction: 0.8), …)` |
| Появление/исчезновение контента | `.transition(.scale(scale: 0.3, anchor: .top)…animation(.easeIn(duration: 0.15)))` |
| Скругление | `radius` (26 открыт / 8 закрыт) |

Ширина открытого острова — `expandedWidth` в `IslandController.swift`, высота — `contentHeight` у каждой фичи.
